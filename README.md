### Featured projects

| Project | Description | Stack |
| --- | --- | --- |
| [**autohealing-e2e-tests**](https://github.com/lluigecm/autohealing-e2e-tests) | Undergraduate thesis. When an E2E selector breaks, it relocates the element by combining structural DOM similarity with stable attributes into a confidence score. Above the threshold the selector is replaced and logged for review; below it the test fails, so real defects aren't masked. | Playwright · TypeScript · POM |
| [**MyGather**](https://github.com/lluigecm/MyGather) | A 2D virtual office in the style of Gather Town, where audio and video connect automatically when avatars get close. The server is authoritative: it validates movement and collisions, authenticates by token, rate-limits events and resumes sessions after disconnects. | TypeScript · Canvas · Socket.io · WebRTC · TURN |
| [**FitTrack**](https://github.com/lluigecm/FitTrack) | A full-stack workout tracker: an exercise catalog, workout logs with sets, reps and load, and a stats dashboard. [Live demo ↗](https://fit-track-rosy.vercel.app) | Angular · NestJS · Prisma · PostgreSQL |
| [**Parallel-Computing-Lab**](https://github.com/lluigecm/Parallel-Computing-Lab) | Benchmarks iterative Gaussian smoothing on 2D images in serial, OpenMP (with tiling), MPI and CUDA versions, with speedup and efficiency analysis. | C · OpenMP · MPI · CUDA |
| [**Weather_Assistant_Pico_W**](https://github.com/lluigecm/Weather_Assistant_Pico_W) | Firmware that fetches OpenWeather data over Wi-Fi via HTTP and shows it on the board display, with screens switched by the board's buttons. | C · Pico SDK · lwIP |
| [**TAC-1**](https://github.com/lluigecm/TAC-1) | Exploratory data analysis of the Stack Overflow Developer Survey, covering career, salary and AI adoption among professional developers. | Python · pandas · SciPy |
